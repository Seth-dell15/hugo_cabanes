# Portfolio — Hugo Cabanes

Portfolio personnel one-page présentant mon parcours, mes projets et mon expérience en développement logiciel, avec une orientation vers les systèmes embarqués et l'aéronautique.

**Voir le portfolio en ligne : [seth-dell15.github.io/hugo_cabanes](https://seth-dell15.github.io/hugo_cabanes/)**

## Aperçu

Le site adopte une interface inspirée d'un cockpit / HUD : fond anthracite, cartes techniques, accents radar verts et cyan, et mise en page responsive.

- **Hero** — profil étudiant et recherche d'alternance au rythme de 2 semaines en entreprise / 1 semaine à l'école.
- **Plan de Vol** — parcours de la formation STI2D et du BIA au Bachelor Informatique, puis objectif systèmes embarqués et simulation aéronautique.
- **Le Hangar** — projets GitHub : [GuardianForge](https://github.com/Seth-dell15/GuardianForge), [FestiPlan](https://github.com/Seth-dell15/FestiPlan), [SmartCampus](https://github.com/Seth-dell15/SmartCampus), [TheLordsStory](https://github.com/Seth-dell15/TheLordsStory) et [Aider](https://github.com/Seth-dell15/Aider).
- **Carnet de Vol** — stage de développement logiciel chez Safran Data Systems, autour de l'automatisation de tests RF et de l'interaction avec du matériel.
- **Systèmes & Avionique** — compétences en développement, embarqué, architectures, données, outils et ingénierie.
- **Tour de Contrôle** — coordonnées, disponibilité pour une alternance et liens professionnels.

## Technologies

- HTML5 et CSS3 (Grid, Flexbox, variables CSS et media queries)
- Aucun JavaScript ni dépendance externe requis

## Lancer le site

Le portfolio est un site statique. Ouvrir `index.html` dans un navigateur ou servir le dossier avec un serveur local. Il peut aussi être publié directement avec GitHub Pages.

Le CV téléchargeable est disponible dans [`assets/CV_Hugo_Cabanes_Alternance.pdf`](assets/CV_Hugo_Cabanes_Alternance.pdf).
